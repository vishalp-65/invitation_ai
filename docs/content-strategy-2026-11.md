# Content Strategy: Noyta (noyta.in)

Written 2026-11-22. Based on the 9 posts and 10 occasion pages in the repo. Search volumes are NOT measured. Priorities below are judgement calls and should be checked in Search Console or Ahrefs before committing writing time.

## Target audience
- Indian families planning a wedding or a family function (roka, griha pravesh, birthday, mundan, naming, nikah, baby shower, anniversary).
- Often the parent or the one person in the family handling the cards. They search in Hinglish, Hindi script and English, and send everything on WhatsApp.
- Buying stage: "I need the words / the card / the video, today, on my phone."

## Internal linking plan
- Every new post links to its occasion landing page (`occasions` field) and to the maker with a mid-article `cta` block, as the existing posts do.
- Each cluster-B post links to one sibling wording post (e.g. namkaran <-> mundan <-> birthday for child ceremonies).
- Hindi/regional posts link to their English counterpart and back.
- Pillar (#16) links to every cluster A post; each of those links back up to it.
- Conversion posts (#10, #11, #14) link to template gallery, pricing and the video/website feature pages.
- Add a "More guides" block at the foot of each post showing 3 related posts by category and occasion.

## Technical notes for the repo
- Add each post as a new file in `apps/web/src/features/blog/posts/` and register in `index.ts`.
- The `category` type only allows Wording, Guides, Planning. Add `'Compare'` if the conversion cluster should have its own section.
- The `occasions` field only accepts occasions that have pages, so haldi/mehndi/sangeet and regional posts need either a new occasion page or an empty array.
- Regional posts need `lang` values beyond `'en' | 'hi'` in the `sample` block (type change in `types.ts`) so fonts and screen readers pick the right language.
- Add hreflang only once regional posts live on separate URLs.
